*Project Title*

***Spatiotemporal Analysis of Mangroves using Median Composites***

This project analyzes the health and changes in mangrove forests over time using satellite imagery and machine learning techniques. The study focuses on the Pichavaram mangrove region in India, covering the years 2014 to 2024.

*Project Overview*

Mangrove forests are crucial to coastal ecosystems but are under threat from climate change and human activities. This project uses multispectral satellite imagery and a Convolutional Neural Network (CNN) model to:

  - Monitor mangrove density classes (sparse, moderate, dense)
  - Perform time series analysis
  - Assess health trends across a decade

*Data Sources*

  - Landsat 8 (2014–2016)
  - Sentinel-2 MSI (2017–2024)

*Area of Interest (AOI)* - Pichavaram, Tamil Nadu, India

*Techniqes Used*

  - Cloud masking and median composite image generation
  - Feature extraction from labeled AOIs
  - CNN-based image classification
  - Time series trend analysis of mangrove extent

*Tools and Libraries*

  - Google Earth Engine (GEE)
  - Google Colab
  - Python: Rasterio, EarthPy, Pandas, NumPy, Keras, Scikit-learn, Matplotlib

*Results*

  - The proposed CNN model achieved an accuracy of 91% in classifying mangrove images.
  - Temporal analysis revealed dynamic shifts in mangrove density across the 10-year span.
  - Trends were visualized through class maps and line plots.
